## Top Headlines

### 1. OpenAI 据报将融资目标削减三分之一至 200 亿美元

据《金融时报》及路透社十月三十日至三十一日的报道，OpenAI 最新融资目标由 300 亿美元调整到约 200 亿美元，拟议估值从 1.4 万亿美元降至 1.25 万亿美元。报道还称，首次交割规模可能低于 200 亿美元；这笔融资尚未完成，数字仍可能变化。其意义是 AI 基础设施需求与私人资本愿意提供的融资条件正在接受新的价格检验，应继续跟踪实际到账资金、算力租赁条款和未来现金支出。[路透社](https://www.reuters.com/business/openai-cuts-funding-target-by-10-billion-ft-reports-2026-10-31/) · [TechCrunch](https://techcrunch.com/2026/10/31/openai-reportedly-lowers-funding-target-for-new-round/)

### 2. 中国央行从十一月二日起将隔夜逆回购操作置于短端利率调控中心

中国人民银行十月三十日公布的操作安排于今天生效：工作日开展隔夜逆回购，采用固定利率、数量招标，公布的操作利率为 **1.25%**；七天期逆回购调整为固定数量、利率招标，更侧重特定时点的流动性管理。这是货币政策操作框架的重要变化，后续需要观察银行间实际短端利率和资金市场表现，而不能把规则实施日直接等同于新的降息决定。[央广财经](https://finance.eastmoney.com/a/202611013917782138.html) · [证券时报](https://stock.10jqka.com.cn/20261101/c681328004.shtml)

### 3. 快手旗下可灵 AI 完成约 198 亿元增资交割

快手十月三十日公告显示，北京可灵投资者实际缴付增资款合计约 **198.02 亿元**，低于原计划上限约 204.47 亿元；快手经 Lucky Labs 持有可灵约 66.68% 股权、52.45% 表决权。部分原认购方未按期缴款后，相关认购被终止或转让。资金完成交割使 AI 视频生成业务的融资从承诺进入到账阶段，但商业回报还需用后续收入、成本和利润数据验证。[快手公告摘要](https://stock.stockstar.com/AN2026103100004465.shtml) · [路透社](https://www.reuters.com/business/retail-consumer/kuaishous-kling-ai-unit-completes-near-3-billion-funding-round-2026-10-30/)

### 4. DeepSeek 开源常驻式 Super-agent 研究原型

DeepSeek Harness 团队十月三十一日公开 `dsh-superagent-prototype`。项目以 Router 分派任务、隔离的 Worker 会话执行工作，能够围绕单个 GitHub 仓库处理授权请求，并可选接入飞书。仓库 README 明确将其称为研究原型，部分设计尚未实现；目前没有充分证据证明它已达到可无人监管地长期生产运行的水平。这是 Agent 架构从单次对话向持续任务管理演化的具体可检查实现。[开源仓库与说明](https://github.com/deepseek-ai/dsh-superagent-prototype)

### 5. 谷歌拟建 500 兆瓦数据中心获得关键地方批准

美国明尼苏达州 Hermantown 市议会十月三十日晚通过谷歌数据中心项目的多项关键土地使用和开发协议。项目规划面积约 170 万平方英尺，预计供电需求约 **500 兆瓦**；但州公用事业监管机构仍需批准供电安排，且相关诉讼尚未解决。这项进展让数据中心的电力、土地和审批约束具备了可以验证的实际项目案例，获批也不等于已经投入运行。[MPR News](https://www.mprnews.org/story/2026/10/31/hermantown-approves-controversial-google-data-center-during-late-night-meeting) · [当地政府项目资料](https://hermantownmn.com/project/)

### 6. 英特尔披露将部分客户端晶圆产能转向服务器处理器

英特尔第三季度财报电话会议中，首席财务官表示，将调整俄勒冈州工厂部分原拟用于 Panther Lake 客户端芯片的 18A 产能，以增加 Intel 3 工艺的数据中心晶圆生产；同时也指出服务器产品仍受封装基板供应约束。这比单纯讨论电脑业务下滑多了一项具体的制造资源重新分配决定，显示服务器需求与个人电脑需求在产线层面产生分化。[英特尔业绩电话会议文字记录](https://stockanalysis.com/stocks/intc/transcripts/714242-q3-2026/) · [Tom's Hardware](https://www.tomshardware.com/pc-components/cpus/intel-confirms-nova-lake-will-use-advanced-18a-p-node-more-details-at-ces-company-says-its-taking-panther-lake-capacity-offline-to-build-more-granite-rapids-data-center-cpus)
