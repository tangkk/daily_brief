## Top Headlines

### 1. 英伟达季度收入达 1158 亿美元，下季指引约 1300 亿美元

英伟达十七日公布的第三财季收入同比增长 **103%**、环比增长 **20%**，达到 **1158 亿美元**；数据中心收入 **1076 亿美元**。按美国通用会计准则，毛利率为 **74.8%**，净利润 **653 亿美元**。公司预计第四财季收入 **1300 亿美元，上下浮动 3%**，但该季度比通常多一周，不能直接把指引增幅当作同口径需求增长。公司称 Vera Rubin NVL72 已开始出货。新增的收入和利润证明上游供货继续扩大；下游客户能否以足够现金收入覆盖设备、供电和融资成本，仍需独立检验。[英伟达原始公告](https://investor.nvidia.com/news/press-release-details/2026/NVIDIA-Announces-Financial-Results-for-Third-Quarter-Fiscal-2027/default.aspx)

### 2. 微软在 Ignite 推出自研编程模型 Code 2

微软十七日宣布 **Code 2** 和 **Code 2 Flash** 已在 GitHub Copilot 与 Foundry 上线，分别面向复杂代码任务和高频轻量任务。公司还称 **Microsoft-Decision-1.1** 已普遍可用，并披露已有超过 **4000 家客户**使用这一决策模型。模型发布使微软在现有第三方模型渠道之外增加自有供给，但公司所称成本性能优势尚需独立任务测试，客户使用数也没有对应的付费收入披露。后续应观察开发者实际选择、单位任务成本和企业合同。[微软 Ignite 主题演讲](https://blogs.microsoft.com/blog/2026/11/17/ignite-2026-building-the-frontier-ecosystem/) · [微软产品汇总](https://news.microsoft.com/source/2026/11/17/microsoft-ignite-2026-empowering-human-ambition-intelligence-and-trust/)

### 3. 百度 AI 云基础设施季度收入增长 94% 至 82 亿元

百度最新季度报告显示，AI 云基础设施收入 **82 亿元人民币**，同比增长 **94%**；其中 GPU 云收入同比增长 **191%**、环比增长 **43%**。公司称千帆平台外部客户的 token 使用收入同比增加 **1159%**，客户预付款及较长期合同增加。这些是比产品发布更直接的付费需求证据，不过同比增幅未说明绝对 token 收入规模。百度 AI 应用收入约 **26 亿元**，同比大体持平，云基础设施扩张尚未同步转化为应用收入增长。报告发表于十六日，相关数据未进入上一期的头条。[百度第三季度业绩公告](https://baidu.gcs-web.com/news-releases/news-release-details/baidu-announces-third-quarter-2026-results)

### 4. 美国十月零售额环比仅增 0.2%，低于九月增速

美国人口调查局十七日公布，十月零售和餐饮销售额经季节调整为 **7482 亿美元**，环比增长 **0.2%**，九月环比增长 **0.8%**。十月同比增长 **6.8%**。该数据未经通胀调整，月度 **0.2%** 变动也处在官方公布的 **±0.4 个百分点**抽样误差范围内，不能单凭一个月认定实际消费收缩。收入、价格和后续修订将决定假日季需求判断。[美国人口调查局数据](https://www.census.gov/retail/sales.html) · [美联社消费者报道](https://apnews.com/article/0f76e8e304f5560e5a3116c4fec5d6b0)

### 5. 美国十月工业产出下降 0.4%，制造业产出仍增 0.3%

美国联邦储备委员会公布，十月工业总产出环比下降 **0.4%**，九月则增长 **0.7%**；制造业产出增长 **0.3%**，公用事业产出下降 **4.3%**，采矿产出下降 **0.8%**。总产出回落由不同部门共同形成，不能误写为制造业同步萎缩。工业产能利用率降至 **76.4%**，比长期平均水平低 **3 个百分点**。联储计划十一月二十四日进行年度数据修订，后续比较需使用修订后的同一序列。[联储工业生产报告](https://www.federalreserve.gov/releases/g17/20261117/g17.pdf)

### 6. 腾讯发布 Hy4 flash，标价每百万输入 token 约 0.07 美元

腾讯十七日推出 **Hy4 flash**：公司称模型总参数 **2240 亿**，其中活跃参数 **120 亿**，支持最长 **100 万 token** 上下文。腾讯公布的标准价格约为每百万输入 token **0.070 美元**、输出 token **0.281 美元**，并已把模型接入云服务和多个内部产品。公司提供的用户满意度对比来自 **85 名内部用户、259 项任务**，不能直接视为独立基准或真实付费规模。价格与部署范围为企业选择模型提供了新样本，实际成本还取决于任务质量和输出长度。[腾讯公告](https://www.prnewswire.co.uk/news-releases/tencent-launches-hy4-flash-to-power-high-speed-cost-efficient-ai-deployment-for-everyday-workflows-302941888.html)

### 7. 家得宝季度销售额增长 4.9%，同店交易次数下降

美国家装零售商家得宝公布第三财季销售额 **434 亿美元**，同比增长 **4.9%**；同店销售额增长 **2.2%**，同店客单价增长 **3.0%**，交易次数下降 **0.5%**。交易量与单笔金额的分化说明销售额增长不能直接等同于顾客到店频次回升。公司将全年同店销售增长指引更新为约 **1.4%**。这为住房相关消费提供了企业层面的新证据，应与零售总额和之后的住房成交数据合看。[家得宝业绩公告](https://ir.homedepot.com/news-releases/2026/11-17-2026-110221331)
